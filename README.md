# QA Path · 测试人的面试题库

面向测试及测试开发工程师的中文面试题库。首版包含知识分类、关键词搜索、难度筛选、排序及分页，题目标准答案与社区回答，邮箱密码注册登录、发布题目、收藏和个人贡献。内置 12 道示例题。

## 开发

需要 Node.js 22.13+（推荐 Node.js 24）。使用 Node 内置 HTTP 和 SQLite，无第三方运行依赖。

```sh
npm start
# 开发时自动重启
npm run dev
# 端到端 API 集成验证
npm test
```

默认监听 `0.0.0.0:3000`。可使用 `HOST`、`PORT` 配置。SQLite 数据默认写入 `data/app.db`，可用 `DB_PATH` 指定位置。首次启动自动建表并导入示例；重启保留数据，不重复导入。已有账号不会被覆盖。

## 使用

游客可浏览问题、标准答案和社区回答。注册登录后可以发布问题（必须同时填写问题描述和标准答案）、回答和收藏。我的收藏与我的贡献仅展示当前账号内容。标签支持中文或英文逗号分隔。当前文本为纯文本展示，支持换行，不解析用户 HTML。

密码采用带随机盐的 scrypt 哈希；会话随机生成、服务端存储摘要，通过 HttpOnly / SameSite Cookie 保存，7 天过期。写接口检查来源；SQL 使用参数绑定；登录注册有基础频率限制。标准答案由题目作者提供，标为社区参考，尚无专家审核。

## 上线前

生产环境需配置 HTTPS，并设置 `COOKIE_SECURE=1`，反向代理保留正确的 Host；备份 SQLite 数据（运行中使用 SQLite 备份 API 或停机后一并处理 WAL）。本版适合单实例使用。尚未实现邮箱验证、密码找回、内容举报与审核、管理员后台、分布式限流和多实例数据库，开放公共注册前应补齐相关运营与安全能力。不要将数据库或用户信息提交到 Git。
